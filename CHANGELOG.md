# Changelog

## v1.0.0 - 2026-09-28

- Defined the first stable public-code version of the field-CPR patient clustering pipeline.
- Public repository includes cohort preparation, feature cleaning, mixed-type distance calculation, hierarchical clustering, validation/external-case assignment, and cluster-level statistical summaries.
- Patient-level clinical data, real cluster assignments, mortality/survival results, p-values, and hospital-specific outputs remain excluded.
